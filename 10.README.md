# Todo App in React Native

## Overview
A simple Todo application built using React Native. The app allows users to add and remove todos, with data persisting in local storage.

## Installation
1. Clone the repository
2. Navigate to the project directory
3. Run `npm install` to install dependencies
4. Start the application with `npx react-native run-android` or `npx react-native run-ios`

## Features
- Add and remove todos
- Persist todos in AsyncStorage
- Cross-platform compatibility
